# Synology Intel GPU Top 0.1.5

Package Center showed Intel GPU Top and AMDGPU Top with identical green graph icons, making it harder to choose the package for the installed GPU. Intel GPU Top 0.1.5 uses a blue graph icon, distinct from the red AMDGPU Top icon.

This is an icon and package metadata update. The Intel executable and its v0.1.4 runtime are unchanged; downstream packages pinned to that runtime do not need rebuilding.

The SPK passed package structure and embedded-icon checks. It has not been reinstalled on DSM hardware as part of this icon-only release.

SPK SHA-256: `cd926bf3097476bda9c2b0feebc415f147dad1776a963312b4aa95de82f5acf1`

## 한국어

Package Center에서 Intel GPU Top과 AMDGPU Top 아이콘이 같은 초록색 그래프로 표시되어 GPU에 맞는 패키지를 고르기 어려웠습니다. Intel GPU Top 0.1.5에는 파란색 그래프 아이콘을 적용해 빨간색 AMDGPU Top 아이콘과 구분했습니다.

이번 변경은 아이콘과 패키지 메타데이터에 한정됩니다. Intel 실행 파일과 v0.1.4 런타임은 그대로이며, 해당 런타임을 고정해 사용하는 파생 패키지는 다시 빌드할 필요가 없습니다.

SPK 구조와 내장 아이콘을 검사했습니다. 아이콘만 바꾼 릴리즈이므로 DSM 실기 재설치는 진행하지 않았습니다.
